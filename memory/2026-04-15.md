## OpenClaw 配置教训

### ❌ 无效配置（导致启动失败）
```json
{
  "skills": {
    "enabled": [...],
    "workspace_dir": "...",
    "auto_discover": true
  },
  "hooks": {
    "external": {...}
  }
}
```
**错误**: `Unrecognized key` - OpenClaw 不识别这些配置

### ✅ 正确做法
- OpenClaw 技能**自动发现**，不需要在 `openclaw.json` 中配置
- 技能放在 `workspace/skills/` 目录即可
- SKILL.md 元数据**不要包含** `requires` 字段（会导致 "needs setup" 状态）

## Hermes Agent 修复

**问题**: `AttributeError: 'ChatCompletionMessageFunctionToolCall' object has no attribute 'get'`

**原因**: 代码期望 dict 对象，但实际是 OpenAI SDK 对象

**修复**: 将 `tc.get("id")` 和 `tc.get("function")` 改为 `getattr(tc, 'id', None)` 和 `getattr(tc, 'function', {})`

**文件**: `~/.hermes/hermes-agent/agent/conversation_loop.py`
- 修复 6 处 `.get()` 调用
- 备份：`conversation_loop.py.bak.20260415193744`

## 技能安装最佳实践

### SKILL.md 元数据模板
```yaml
---
name: skill-name
description: 简洁描述（不超过 100 字）
homepage: https://github.com/user/repo
metadata: {"openclaw":{"emoji":"🔧"}}
---
```

### 不要添加
- ❌ `requires` 字段
- ❌ `bins` 依赖声明
- ❌ 任何 OpenClaw 不识别的配置

### 目录结构
```
workspace/skills/skill-name/
├── SKILL.md
├── scripts/
│   ├── verify.ps1
│   ├── install.ps1
│   └── test.ps1
├── references/
└── examples/
```
