# 2026-04-26 记忆

## 视频脚本生成器优化
- 问题发现：脚本生成逻辑有4个深层问题
  1. 模板填充方式，不是真正讲故事
  2. 脚本没有"人味"，像机器读报告
  3. 缺少叙事结构（起承转合）
  4. 视角是经纪人视角，不是观众视角
- 尝试方案：重写脚本生成逻辑（v105-v162）
- 核心思路：先让AI读跟进记录，理解内容，找出闪光点，然后用闪光点展开生成脚本
- 执行结果：脚本执行完成，但生成的脚本质量仍有问题
- 待解决：需要进一步改进脚本生成逻辑，真正实现故事化叙述

## 技能执行机制
- 问题：技能文件是静态文档，描述理想行为但没有机制强制执行"等待"步骤
- 影响：AI倾向于一次性读完并执行所有规则
- 缓解方案：引导语 + 用户明确指令配合使用
- 根本限制：无法做到100%可靠，依赖模型自觉

## 用户反馈要点
- 佳佳强调：视频是给人看的，不是给机器看的
- 脚本需要从底层重新思考，不是肤浅对比
- 应该先让AI读跟进记录，理解内容，找出闪光点
- 然后用闪光点展开生成脚本，不是生硬套模板
