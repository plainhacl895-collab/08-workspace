# Property View - 房源查看技能 🌐

- ✅ 截图保存房源

## ⚙️ 配置选项

### 打开参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--id` | 房源 ID | 必需 |
| `--ids` | 多个房源 ID | - |
| `--client` | 客户名 | - |
| `--limit` | 打开数量限制 | 10 |
| `--new-tab` | 新标签页打开 | 是 |

### 登录参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--auto-login` | 自动登录 | 是 |
| `--username` | 账号 | 配置文件 |
| `--password` | 密码 | 配置文件 |
| `--save-cookie` | 保存 Cookie | 是 |

### 截图参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--screenshot` | 截图 | 否 |
| `--save-dir` | 保存目录 | 桌面 |
| `--full-page` | 全屏截图 | 是 |
| `--format` | 图片格式 | png |

## ⚠️ 注意事项

### 1. 浏览器限制

**限制**：
- ⚠️ 最多同时打开 10 个标签页
- ⚠️ 部分网站禁止自动化
- ⚠️ 需要手动完成验证码

**解决**：
- ✅ 分批打开（每次 10 套）
- ✅ 使用浏览器插件
- ✅ 手动处理验证码

---

### 2. 登录状态

**要求**：
- ✅ 保持登录状态
- ✅ 定期更新 Cookie
- ✅ 避免频繁登录

**建议**：
- ✅ 使用 Cookie 登录
- ✅ 每周重新登录一次
- ✅ 不要频繁切换账号

---

### 3. 截图保存

**注意**：
- ✅ 截图文件较大
- ✅ 需要足够磁盘空间
- ✅ 定期清理旧截图

**建议**：
- ✅ 只截图重点房源
- ✅ 压缩保存图片
- ✅ 每月清理一次
