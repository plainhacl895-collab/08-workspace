# Client Query - 客户查询技能 👤

## 技能描述

专业查询客户详细信息的技能，支持按姓名、电话、行号查询。

**核心功能**：
- ✅ 按姓名查询客户
- ✅ 按电话查询客户
- ✅ 按行号查询客户
- ✅ 获取客户详细信息
- ✅ 获取客户跟进记录
- ✅ 获取推荐房源列表

## 🚀 使用方法

### 方式 1: 命令行查询

```cmd
REM 按姓名查询
cmd /c query-client.cmd --query "刘先生"

REM 按电话查询
cmd /c query-client.cmd --query "13816739609"

REM 按行号查询
cmd /c query-client.cmd --query "12"
```

### 方式 2: Python 脚本

```cmd
python query_client_simple.py --query "刘先生"
```

### 方式 3: 团团 CLI

```cmd
cmd /c RUN_TUANTUAN_qidong.cmd client-search --query "刘先生"
```

## ⚙️ 配置选项

### 查询参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--query` | 查询条件（姓名/电话/行号） | 必需 |
| `--limit` | 返回结果数量 | 10 |
| `--followup-limit` | 返回跟进记录数量 | 3 |

### 输出格式

| 格式 | 参数 | 说明 |
|------|------|------|
| **文本** | 默认 | 人类可读格式 |
| **JSON** | `--json` | 机器可读格式 |
| **简洁** | `--quiet` | 只输出关键信息 |

## ⚠️ 注意事项

### 1. 缓存问题

**问题**：查询结果可能是缓存数据

**解决**：
```
如果 Excel 表格有更新，请先刷新缓存：
cmd /c RUN_TUANTUAN_qidong.cmd refresh
```

---

### 2. 多结果处理

**问题**：查询条件匹配多个客户

**解决**：
```
找到多个匹配客户时，请提供更精确的查询条件：
- 使用完整姓名
- 使用电话号码
- 使用行号
```

---

### 3. 查询失败

**问题**：找不到客户

**解决**：
```
1. 检查查询条件是否正确
2. 检查客户是否存在
3. 检查缓存是否需要刷新
4. 尝试使用行号查询
```

## 📋 错误处理

### 常见错误码

| 错误码 | 说明 | 解决方法 |
|--------|------|----------|
| **NOT_FOUND** | 客户不存在 | 检查查询条件 |
| **MULTIPLE_FOUND** | 匹配多个客户 | 提供更精确条件 |
| **CACHE_EXPIRED** | 缓存过期 | 刷新缓存 |
| **EXCEL_LOCKED** | Excel 被锁定 | 关闭 Excel 后重试 |
