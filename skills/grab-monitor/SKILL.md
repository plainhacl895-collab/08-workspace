## 📋 配置选项

### 监控参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--task-id` | 任务 ID | 最新任务 |
| `--interval` | 监控间隔（秒） | 300 |
| `--output` | 输出格式 | text |
| `--verbose` | 详细模式 | 否 |

### 报告参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--date` | 报告日期 | 今天 |
| `--area` | 区域过滤 | 全部 |
| `--format` | 报告格式 | text |
| `--export` | 导出文件 | 否 |

## ⚠️ 注意事项

### 1. 监控时机

**最佳时机**：
- ✅ 抓取开始后 5 分钟
- ✅ 抓取过程中每 30 分钟
- ✅ 抓取完成后立即

**避免**：
- ❌ 抓取刚开始（数据不稳定）
- ❌ 深夜打扰（非紧急）

---

### 2. 错误处理

**发现错误时**：
1. ✅ 记录错误详情
2. ✅ 分析错误原因
3. ✅ 尝试自动重试
4. ✅ 人工介入（如需要）

**常见错误**：
- ✅ 网络超时 → 重试
- ✅ 解析失败 → 检查网站结构
- ✅ 写入失败 → 检查 Excel 状态

---
