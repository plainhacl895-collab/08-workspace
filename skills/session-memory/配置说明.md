# 自动记忆保存配置

## 每次会话结束自动保存

在 `~/.openclaw/hooks/session-memory/config.yaml` 中配置：

```yaml
enabled: true
auto_save: true
save_triggers:
  - code_changes
  - script_modifications
  - error_corrections
importance_rules:
  error_correction: critical
  code_change: high
  script_change: high
```

## 手动保存重要记忆

```bash
# 保存错误教训（critical 级别，每次必现）
MEMORY_IMPORTANCE=critical ~/.openclaw/workspace/skills/session-memory/scripts/save.sh "错误教训" "改代码前必须先 read 完整文件，不要截断代码" 错误 代码修改

# 保存配置决策
MEMORY_IMPORTANCE=high ~/.openclaw/workspace/skills/session-memory/scripts/save.sh "配置规则" "HEARTBEAT.md 必须读取 workspace 路径，不是 docs 路径" 配置 路径

# 保存执行流程
MEMORY_IMPORTANCE=high ~/.openclaw/workspace/skills/session-memory/scripts/save.sh "执行流程" "修改脚本前先备份，执行时设置 timeout，定期检查进度" 脚本 执行
```

## 每次会话启动自动加载

```bash
# 加载最近 7 天的记忆 + 所有 critical/high 级别记忆
~/.openclaw/workspace/skills/session-memory/scripts/context.sh --days 7
```

## 查看已保存的记忆

```bash
# 搜索所有错误相关记忆
~/.openclaw/workspace/skills/session-memory/scripts/recall.sh "错误"

# 查看所有 critical 级别记忆
~/.openclaw/workspace/skills/session-memory/scripts/recall.sh "" --importance critical

# 查看统计
~/.openclaw/workspace/skills/session-memory/scripts/stats.sh
```
