# Refresh Cache - 刷新缓存技能 🔄

## 技能描述

专门用于刷新团团助手的 CSV 缓存，确保数据与 Excel 表格同步。

**使用场景**：
- ✅ 在 Excel 中写入新跟进后
- ✅ 添加新客户后
- ✅ 删除无效客户后
- ✅ 修改客户信息后
- ✅ 机器人找不到最新数据时

**触发指令**：
- "刷新缓存"
- "更新缓存"
- "刷新数据"
- "更新数据"
- "缓存过期了"
- "数据没同步"

---

## 🚀 使用方法

### 方式 1: 命令行刷新

```cmd
cmd /c RUN_TUANTUAN_qidong.cmd refresh
```

**输出**：
```
正在刷新缓存...
[OK] 缓存已刷新
[OK] 客户数：162
[OK] 缓存生成时间：2026-04-17T21:15:00
```

---

### 方式 2: 自动刷新

以下操作会**自动刷新缓存**：
- ✅ `write-followup` - 写入跟进后
- ✅ `client-update` - 更新客户后
- ✅ `delete-followup` - 删除跟进后

---

### 方式 3: 检查缓存状态

```cmd
cmd /c RUN_TUANTUAN_qidong.cmd doctor
```

**输出**：
```
缓存状态：有效
缓存时间：2026-04-17T21:15:00
Excel 时间：2026-04-17T21:10:00
状态：✅ 同步
```

## ⚠️ 注意事项

### 1. 刷新前确保 Excel 已保存

```
❌ 错误：Excel 还在编辑中就刷新
✅ 正确：先保存 Excel，再刷新缓存
```

### 2. 刷新时不要打开 Excel

```
❌ 错误：Excel 打开时刷新（会等待关闭）
✅ 正确：关闭 Excel 后再刷新
```

### 3. 刷新后等待完成

```
❌ 错误：刷新中途关闭
✅ 正确：等待 [OK] 缓存已刷新 提示
```

## 📝 常见问题

### Q1: 为什么要刷新缓存？

**A**: 缓存是为了提高查询速度，但如果 Excel 数据变化了，缓存就会过期。刷新缓存可以确保数据最新。

---

### Q2: 多久刷新一次？

**A**: 
- **有数据变化**：立即刷新
- **无数据变化**：24 小时自动刷新
- **不确定**：随时可以手动刷新

---

### Q3: 刷新失败怎么办？

**A**: 
1. 确保 Excel 文件已关闭
2. 确保 Excel 文件已保存
3. 重新运行刷新命令
4. 如果还失败，检查 Excel 文件路径

---

### Q4: 刷新后数据还是旧的？

**A**: 
1. 检查 Excel 是否已保存
2. 检查缓存文件位置是否正确
3. 手动删除缓存文件后重新刷新
4. 运行 `doctor` 命令检查状态
