# 表格客户操作系统

这个目录保存 Excel 业务资产、旧版 PowerShell 脚本、抓取流程脚本和说明文档。

## 当前定位

- 这是业务资产目录，不是当前统一命令入口
- 当前统一入口在：`..\tools\RUN_TUANTUAN_qidong.cmd`
- 当前实际执行程序在：`..\tools\main.py`

## 目录说明

- `1_biaoge_jiaoben/`：旧版 Excel/PowerShell 脚本
- `2_wangye_zhuaqu_xieru/`：旧版房源抓取与写入脚本
- `3_biaoge_caozuoshiyong_shuoming/`：旧版说明文档
- `daily_followup.xlsm`：业务工作簿或副本
- `_house_grab_runtime/`、`_house_grab_logs/`、`_house_grab_backups/`：历史抓取运行产物

## 使用建议

1. 想看当前整体结构，先读 `..\workspace\docs\architecture.md`。
2. 想执行生产命令，走 `..\tools\RUN_TUANTUAN_qidong.cmd`。
3. 想回看历史脚本或说明，再进入本目录的子文件夹。
